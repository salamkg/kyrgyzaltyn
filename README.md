# ОАО «КыргызАлтын» — Корпоративный портал и система управления (CMS/Admin)

Полнофункциональный веб-портал и административная панель для ОАО «КыргызАлтын», разработанные на базе **Laravel** и **Filament Admin**. Проект полностью адаптирован под требования официального сайта компании и содержит все необходимые разделы: новости, правление, совет директоров, филиалы, тендеры, отчеты и котировки золотых слитков.

---

## 🛠 Технологический стек

* **PHP 8.2+**
* **Laravel 11**
* **Filament PHP 3** (Административная панель)
* **MySQL** (База данных)
* **Tailwind CSS / Blade**

---

## 🚀 Быстрый старт для проверки проекта

Чтобы развернуть проект локально и сразу увидеть его со всеми наполненными данными (новости, руководство, филиалы, тендеры), выполните следующие команды в терминале:

### 1. Клонирование репозитория
```bash
git clone [https://github.com/salamkg/kyrgyzaltyn.git](https://github.com/salamkg/kyrgyzaltyn.git)
cd kyrgyzaltyn

### 2. Установка зависимостей PHP и JavaScript
composer install
npm install && npm run build


### 3. Настройка окружения
Скопируйте файл конфигурации и сгенерируйте ключ приложения:

cp .env.example .env
php artisan key:generate


### 4. Запуск миграций и наполнение базы данных (Seeders)
Выполните одну команду, которая очистит базу, создаст все таблицы и автоматически заполнит сайт реалистичными данными (новостями, руководящим составом, отчетами и ценами на мерные слитки):

php artisan migrate:fresh --seed


### 5. Запуск локального сервера
php artisan serve



После этого проект будет доступен по адресу: http://127.0.0.1:8000
